## 1. Executive Summary

Stage 4E-IMP-05 implements the formal scientific evaluation, multi-rater annotation, statistical calibration, and human review infrastructure for Anvīkṣā. The subsystem assesses the methodological defensibility, empirical reproducibility, and epistemic reliability of artifacts generated by all preceding Stage 4E subsystems:
- **4E-IMP-01:** Research Opportunity Intelligence (Intrinsic Value $V_{scientific}$, orthogonal dimensions, non-compensatory gates).
- **4E-IMP-02:** Falsifiable Hypothesis Engine (10-point Popperian falsifiability rubric, operational variables, non-tautology).
- **4E-IMP-03:** Experiment Protocol Synthesizer ($BAR = 100\%$, $PCI \ge 8.5/10.0$, 11 experimental paradigms, pre-specified statistical falsification criteria).
- **4E-IMP-04:** Resource Suitability and Strategic Recommendations ($E_{suitability}$, discrete evidence states, 2D Strategic Decision Matrix, elimination of composite scalar collapse).

In strict adherence to the frozen Stage 4E architecture, 4E-IMP-05 enforces:
1. **Multi-Criterion Quality Evaluation:** Decoupled scoring dimensions preventing false aggregation.
2. **Double-Blind BIBD Annotation:** Balanced Incomplete Block Design schedules with conflict-of-interest management.
3. **Rigorous Statistical Engines:** Tie-corrected Kendall's $\tau_b$ with $B=2000$ Paired Stratified BCa Bootstrap and $B=10000$ permutation tests; bounded non-parametric BCa bootstrap for $PCI$ on $[0.0, 10.0]$ alongside Bayesian Squeezed Beta transformation ($p^*$).
4. **Inter-Rater Reliability:** Krippendorff's alpha ($\alpha_{Kripp} \ge 0.70$ on $N=20$ pilot calibration), Fleiss' kappa, and $\text{ICC}(2, k)$ with honest missing-value and degenerate-distribution handling.
5. **Formal Human Review & Scientific Arbitration:** Multi-criterion review submissions, strict demarcation of author self-reviews (preventing self-promotion to `RESEARCHER_APPROVED`), automatic disagreement escalation (rating delta $> 1.5$ or split votes), and automated invalidation triggers upon parent artifact revisions.

## 3. Database Schema & Privilege Architecture

### 3.1 Enhanced `public.researcher_reviews` Table
The existing table was additively extended with required auditing, criterion scoring, and invalidation fields:
```sql
ALTER TABLE public.researcher_reviews
    ADD COLUMN IF NOT EXISTS criterion_scores JSONB NOT NULL DEFAULT '{}'::jsonb,
    ADD COLUMN IF NOT EXISTS reviewer_role TEXT NOT NULL DEFAULT 'INDEPENDENT_PEER',
    ADD COLUMN IF NOT EXISTS is_self_review BOOLEAN NOT NULL DEFAULT false,
    ADD COLUMN IF NOT EXISTS adjudication_notes TEXT,
    ADD COLUMN IF NOT EXISTS is_invalidated BOOLEAN NOT NULL DEFAULT false,
    ADD COLUMN IF NOT EXISTS invalidation_reason TEXT,
    ADD COLUMN IF NOT EXISTS entity_version INTEGER NOT NULL DEFAULT 1;
```

### 3.2 Automated Evaluation Runs (`public.research_evaluations`)
Stores immutable records of multi-criterion audits, benchmark evaluation runs, and statistical validation outputs:
- `id`: UUID primary key.
- `entity_type`: `'OPPORTUNITY'`, `'HYPOTHESIS'`, `'EXPERIMENT'`, `'SUITABILITY'`, `'BENCHMARK_BATCH'`.
- `evaluation_mode`: `'AUTOMATED_RUBRIC'`, `'MULTI_RATER_PILOT'`, `'BENCHMARK_RUN'`, `'STATISTICAL_VALIDATION'`.
- `overall_score`: Numeric scalar in $[0.0, 10.0]$.
- `passed_gates`: Boolean summary of non-compensatory gates.
- `metrics`: JSONB dictionary of domain-specific metrics ($HFI$, $BAR$, $\tau_b$, $PCI$, $RUS$).
- `criterion_scores`: JSONB array of detailed rubric criteria.
- `statistical_evidence`: JSONB payload containing bootstrap intervals, permutation p-values, and alpha metrics.

### 3.3 BIBD Rater Allocations (`public.research_reviewer_allocations`)
Tracks balanced rater schedules and conflict-of-interest declarations:
- `id`: UUID primary key.
- `study_id`: Text identifier (e.g. `'PILOT_STUDY_N20'`, `'BENCHMARK_2026'`).
- `artifact_type`: `'HYPOTHESIS'`, `'EXPERIMENT'`, `'OPPORTUNITY'`.
- `artifact_id`: UUID of the evaluated artifact.
- `reviewer_id`: UUID foreign key to `auth.users(id)`.
- `block_index`: Integer index of the BIBD block.
- `domain_specialty`: Text field identifying domain qualification.
- `status`: `'PENDING'`, `'COMPLETED'`, `'EXCUSED_COI'`, `'REPLACED'`.
- `coi_declared`: Boolean flag indicating declared institutional/author conflict.

### 3.4 Privileged Server RPCs & RLS Policies
All mutations are strictly guarded behind PostgreSQL Row-Level Security:
- `rls_reviews_block_client_insert`: Direct client SQL `INSERT` is blocked (`WITH CHECK (false)`).
- `rls_evaluations_block_client_insert`: Direct client SQL `INSERT` is blocked (`WITH CHECK (false)`).
- `rls_reviews_anon_block_all`: Anonymous access is completely blocked (`USING (false) WITH CHECK (false)`).
- **Atomic RPCs:**
  - `rpc_submit_researcher_review`: Authenticated review submission enforcing author vs peer review role logic.
  - `rpc_record_research_evaluation`: Service-role evaluation logging.
  - `rpc_invalidate_entity_reviews`: Invalidates active reviews and resets status when parent entities evolve.

## 5. Frontend Evaluation Workbench Integration

The `ScientificEvaluationWorkbench.tsx` component is fully integrated into the Anvīkṣā user interface:
1. **Interactive Quality Audit View:** Live inspection of generated opportunities, hypotheses, and protocols with criterion-by-criterion status tags, scoring explanations, and gate compliance.
2. **Formal Human Review Submission Form:** Structured Likert scale ratings (1–5), reviewer role selector, author self-review demarcation warnings, parameter revision payload editor, and senior arbitration notes.
3. **Statistical Inference Lab:** Interactive calculators for Kendall's $\tau_b$ (with paired BCa confidence intervals and permutation test p-values) and $PCI$ distribution calibration (comparing bounded BCa bootstrap with Bayesian Squeezed Beta).
4. **Inter-Rater Reliability Lab:** Interactive Krippendorff's alpha calculator supporting partial matrices with missing ratings and BIBD schedule visualization.
5. **Immutable Audit History View:** Real-time log of recorded reviews, displaying reviewer role, decision, timestamp, and staleness/invalidation tags.
